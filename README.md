# Kovva Style Waitlist

Create a waitlist landing page for "Kovva" — an Instagram-like mobile app for fashion enthusiasts. The app is already in development; this page collects early-access sign-ups.

## What Kovva Is

Kovva is where fashion lovers discover, share, and shop personal style. Think Instagram's visual feed, but exclusively for fashion — outfit posts, style inspiration, tagged products, and creator insights. You can use AI to style yourself on outfits, and if people buy the outfit from your post, you earn a commission.

## Brand Colors

- Background: #1b1b1b (dark surface)

- Accent (lime green): #a7ff27 — CTAs, highlights, active states

- Secondary (soft green): #e7ffc7 — light fills, inputs

- Button text on green: #385915

- Body text: #d9d9d9

- Muted text: #a3a3a3

- Strong text: #f3f3f3

- Raised surface / cards: #242424

- Control surface: #3f3f3f

- Input background: #f5ffea

- Border: #4c4c4c

## Typography

Font: Inter (Google Fonts). Weights: 400, 500, 700.

Display: 32px · Title: 20px · Body: 16px · Caption: 13px

## Border Radius

Small: 8px · Medium: 12px · Large: 16px · Pill: 999px

## Page Requirements

- A hero section with a headline, short description of Kovva, and an email capture form

- The waitlist form should collect: Name, Email, Phone Number, and Occupation (optional)

- Input style: background #f5ffea, text #42651a, placeholder #42651a, rounded 16px, height 54px

- Primary CTA button: #a7ff27 background, #385915 text, rounded 16px

- A short footer with copyright and basic links

- Dark theme throughout — the page should feel like the app itself

- Mobile-first responsive design

## Style Direction

Premium, clean, fashion-editorial — not startup-generic. Generous whitespace, large type, dark backgrounds. The vibe should feel like a high-end fashion brand's landing page, not a tech product.

## Asset Placeholders

Leave placeholder areas for the AI to fill. Describe what should go in each:

- Hero visual: A short looping video (5–10s) or static image showing a stylized phone mockup of the Kovva app with an outfit post in the feed. Dark phone frame, vibrant outfit photo inside. 9:16 for phone mockup or 16:9 for wide hero.

- Feature/mood visuals: A grid or flat-lay of 4–6 diverse outfit photos — streetwear, casual, Afrocentric, minimal, bold color. A mini mood board showing the breadth of fashion on Kovva.

- Icons: Simple outline icons (stroke 2px, #a7ff27, transparent bg) for any feature callouts. SVG preferred.

## Do Not

- Use stock photos of generic "people on phones"

- Make it look like a SaaS landing page

- Use light backgrounds
